# Devixo Solutions AI/ML Internship Program. Task 01

## 📌 Project Netflix Content Data Analysis, Visualization & Interactive Dashboard

## 🎯 Project Objective

The goal of this task is to do a look at the Netflix media catalog dataset. I will clean data analyze it and make charts. This work builds a base for AI/ML tasks by spotting trends in what Netflix releases, when and where. I also create a Streamlit web app.

## 📊 Dataset Description

* **Dataset Name:** `Dataset.csv`

* **Description:** Holds details of movies and TV shows on Netflix with fields like title, director, cast, country, release year, rating, duration and genre list.

## 🌐 Dataset Source

* Supplied by Devixo Solutions and the Kaggle Netflix Movies and TV Shows Dataset repository.

## 🛠️ Technologies Used

* **Programming Language:** Python

* **Environment & Tools:** VS Code, Google Colab, Jupyter Notebook, Git & GitHub

* **Web Framework:** Streamlit

## 📚 Libraries Used

* **Data Manipulation & Processing:** `pandas` `numpy`

* **Data Visualization:** `matplotlib` `seaborn`

* **Interactive Dashboard:** `streamlit`

## 🔄 Project Workflow

1. **Data Loading:** I loaded the Netflix catalog CSV into a Pandas DataFrame.

2. **Data. Preprocessing:** I looked for missing values fixed them removed duplicates and made year data consistent.

3. **Exploratory Data Analysis (EDA):** I examined how Netflix content spreads over years between Movies and TV Shows and by country of production.

4. **Statistical Analysis:** I calculated stats and counted how often each category and number appear.

5. **Data Visualization:** I made clear high‑quality charts. Stored them in the project folder.

6. **Dashboard Development:** I created a Streamlit web app (`app.py`) that lets users filter and view Netflix data live.

## 💡 Major Findings & Insights

1. **Content Type Imbalance:** Movies are many more than TV Shows in the Netflix catalog.

2. **Production Boom:** Netflix added a lot content each year from 2018 to 2021.

3. **Top Genres:** International movies, dramas, comedies and documentaries are the categories in Netflix.

4. **Maturity Ratings:** TV‑MA and TV‑14 are the common age ratings, in Netflix.

5. **Global Distribution:** The United States and India produce the Netflix content worldwide.
